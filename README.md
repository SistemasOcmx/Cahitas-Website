# Cahita Constructora

Sitio editorial de una página para Cahita Constructora, desarrollado con React, Vite, TypeScript, Tailwind CSS y GSAP.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```bash
npm install
npm run dev
```

Vite mostrará la dirección local al iniciar.

## Producción

```bash
npm run build
npm run preview
```

Las imágenes de marca se sirven desde `public/img`. La subcarpeta `public/img/webp` contiene versiones optimizadas para el sitio; los archivos originales se conservan.

El formulario prepara un correo para `cahitaobras@gmail.com` en la aplicación de correo de la persona visitante; no envía datos a un servidor.
